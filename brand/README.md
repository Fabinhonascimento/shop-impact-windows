# Shop Impact Windows – Brand kit

Open `brand-guide.html` for the visual guide.

| File | Use |
|---|---|
| `svg/logo-horizontal-color.svg` / `png/…` | Main logo on white/light backgrounds (website, documents, email) |
| `svg/logo-horizontal-white.svg` / `png/…` | Main logo on dark backgrounds or photos |
| `svg/logo-stacked-*.svg` | Square spaces: social media, signs, shirts |
| `svg/icon-*.svg` | Icon only: favicon, stamps, small spaces |
| `svg/app-icon.svg`, `png/app-icon-1024.png` | Profile picture (Instagram, WhatsApp, Google Business) |

SVG files are vector (text converted to outlines) – send these to print shops.
PNG files have transparent backgrounds.

**Colors:** Storm Navy `#0B2540` · Impact Blue `#0EA5E9` · Sky Glass `#38BDF8` (on dark) · White `#FFFFFF`
**Font:** Montserrat (ExtraBold 800 / SemiBold 600) – free on Google Fonts.
